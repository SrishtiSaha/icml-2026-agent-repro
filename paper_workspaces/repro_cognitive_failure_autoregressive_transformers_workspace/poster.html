4. Scaling: 7B Reversal Fails

Lower mean entropy indicates stronger collapse. TinyLlama-Chat supports sub-3B instruction collapse, but Falcon-7B-Instruct still collapses more than Falcon-7B base.

The sweep is observational, matching the paper's caveat: architectures and alignment recipes vary, so the direct test is whether the reported direction appears under matched decoding.

ModelTypeEntropy
Falcon-RW-1BBase2.439
TinyLlama-1.1B-ChatInstruct1.118
OPT-1.3BBase2.492
Falcon-7BBase2.293
Falcon-7B-InstructInstruct0.777

Each model used 20 HotpotQA prompts, matched sampling, and 48-token entropy traces. The reversal test is therefore direct: base and instruct Falcon-7B are compared within one model family.

Result interpretation: the instruct curve is non-monotonic only if it rises at 7B; here it drops sharply, so the reversal is absent.
